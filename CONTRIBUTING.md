# Contributing

Thanks for checking out the project!

## How this works

1. Take a look at the [open issues](../../issues) — maybe something there is already what you want to do.
2. Nothing fits? Open a new issue describing what you'd like to add or fix.
3. Drop a comment saying you're picking it up. I'll assign it to you if I can — if not, consider it yours once you've commented.
4. Fork, make your changes, open a PR that references the issue.

## A few ground rules

- Keep PRs focused on one thing — easier to review, easier to merge.
- Please don't touch `.gitignore`, `.vscode/extensions.json`, or other project config files unless the issue is specifically about that. Random unrelated changes there just create merge conflicts.
- If your change touches wiring/pinout, mention it clearly in the PR.

No strict process beyond that — just shout before starting anything big so we don't step on each other's toes.
